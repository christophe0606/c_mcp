# CMSIS-MCP documentation

The documentation for the development branch is published under `main/`:
https://christophe0606.github.io/c_mcp/main/.

The source repository's pack workflow updates this branch. The GitHub Pages
workflow deploys it. Keep the root assets when updating generated HTML:
`version.js`, `version.css`, `dropdown.png`, `update_versions.sh`, and
`index.html`.

The version selector assets and update script are adapted from
[CMSIS-DSP](https://github.com/ARM-software/CMSIS-DSP/tree/gh-pages), licensed
under Apache-2.0. They are maintained here for CMSIS-MCP. See `LICENSE.md`.
