cJSON * create_result_text ( const char * text)
extern

Build an MCP tool result containing one text content item.

Parameters
[in]textNon-NULL, null-terminated text to copy.
Returns
Borrowed reusable template during dispatch (NULL if arena copying fails), or heap-owned cJSON result outside dispatch.

Returns content with type=text, without a JSON-RPC envelope. Use ok() to wrap it. Registered callbacks return plain text: the core invokes this helper for them. Do not delete/retain the dispatch template.

Example
cJSON *result = create_result_text("Ready");
cJSON_Delete(result); // Only when called outside dispatch.

◆ ok()

cJSON * ok ( cJSON * id,
cJSON * result )
extern

Wrap a result in a JSON-RPC success envelope.

Parameters
[in]idBorrowed request ID; supply a valid cJSON ID, including JSON null.
[in]resultResult object; borrowed during dispatch. Outside dispatch its ownership transfers to the returned envelope.
Returns
Borrowed reusable template during dispatch, or heap-owned envelope outside dispatch.

Outside dispatch, id is deep-copied. During dispatch, id/result are referenced and must remain valid until serialization. Do not delete or retain the borrowed response; subsequent calls can overwrite it.

Example
cJSON *id = cJSON_CreateNumber(1); // Outside dispatch.
cJSON *response = ok(id, create_result_text("Ready"));
// Use response; do not separately delete its adopted result.
cJSON_Delete(response);
cJSON_Delete(id);
