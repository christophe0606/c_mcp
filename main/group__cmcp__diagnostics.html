◆ mcp_heap_allocations()

size_t mcp_heap_allocations ( void )
extern

Count allocation attempts through the installed cJSON heap allocator.

Returns
Cumulative cJSON heap-allocation attempts outside dispatch.

Not a byte count or a count of every allocation. Direct malloc calls for registry nodes are not included; failed cJSON allocations are counted. Requests should not increase this counter after mcp_prepare() succeeds.

Example
size_t before = mcp_heap_allocations(); // After successful mcp_prepare().
dispatch("{\"jsonrpc\":\"2.0\",\"id\":3,\"method\":\"ping\"}", 0);
size_t after = mcp_heap_allocations(); // Expected to equal before.

extern

Read the comparison count of the latest tool-name lookup.

Returns
Number of string comparisons; zero for a NULL lookup or empty index.

Registration and tools/call also perform lookups and can update it.

Example
